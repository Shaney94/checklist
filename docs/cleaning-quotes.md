# Public cleaning quotes (V1)

`/quote` is a noindex conversion page, excluded from the public sitemap. Marketing content stays server-rendered. `/api/quote` accepts validated property details without authentication, calculates on the server and never stores anonymous details. No address lookup service is used: town, area or postcode is enough.

`lib/cleaning-price.cjs` is the single pricing configuration/model. The 52 m², two-bedroom, two-bed, one-bathroom calibration yields £60 / approximately 2 hours Regular and £130 / approximately 4–4.5 hours Deep. Supplies and normal linen/towel wash and dry are included. These are customer prices, not wages, payouts or commissions.

Coefficients are conservative business assumptions, not measured labour data. Each standard has its own base duration and added minutes for floor area, bathrooms and beds. Known area does not independently charge for bedrooms. Unknown area uses a direct bedroom labour allowance plus beds/bathrooms, never a fabricated area. Only increases above the reference inputs add time; minimum prices are £60/£130, rounded up to £5. Frequency is recorded but has no price effect. Change the model version when tuning coefficients; historical saved quotes retain their version and calculated result.

Continue uses a 30-minute, tab-scoped session draft only after explicit user action. The existing login/register flow returns to the exact allowlisted `/quote` route. Authenticated confirmation recalculates and saves the quote on a new property in the existing dashboard JSON, with unchanged standard templates. No new property model, migration, authentication flow or role assignment is added. Hosts use their authorised managed workspace; Cleaners use their own customer workspace. A request UUID and optimistic workspace revisions make retries idempotent. Saved-quote reads require both the current managed workspace and creating account. No client-provided price or workspace is accepted.

Property-specific guidance/applicability can be configured in the existing authorised workspace. Photos/floor plans, matching, marketplace posting, bookings and payment are not part of this flow. Quote time estimates are not proof of checkout or a scheduled cleaning job.

Verification: `npm run verify`; `npm run test:integration -- tests/quote.integration.test.cjs` against isolated local PostgreSQL; production build and focused `tests/e2e/quote.spec.ts`, Glasgow/SEO entry-point checks. No production credentials or real external emails are used.

Local development uses the same central Origin validator as production: `npm run dev` accepts exactly `http://localhost:3000` and `http://127.0.0.1:3000`. For another port or a local production build, start with an explicit server environment value, for example `TURNLI_LOCAL_ORIGIN=http://localhost:3000 npm start`. Only an exact HTTP localhost/127.0.0.1 origin with a valid port is accepted. Vercel deployments ignore this setting; production without this explicit local opt-in retains only the two established production origins. Never derive allowed origins from incoming Host/forwarded headers. Browser fixtures configure their exact loopback origin and do not rewrite quote requests.
